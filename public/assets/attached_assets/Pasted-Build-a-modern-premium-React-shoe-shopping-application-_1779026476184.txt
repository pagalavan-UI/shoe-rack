Build a modern premium React shoe shopping application called “Shoe Rack” with two separate role-based UI apps:

1. User App (Main Focus)
2. Admin App

IMPORTANT:
- UI only
- No backend
- No database
- Use static/mock JSON data
- Use React + Vite + Tailwind CSS + Framer Motion
- Modern luxury sneaker brand style UI
